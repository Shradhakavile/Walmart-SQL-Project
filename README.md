# Walmart-SQL-Project
SQL analysis on Walmart sales dataset using MySQL Workbench

# Walmart Sales Data Analysis using SQL

# Project Overview
This project analyzes Walmart sales data to uncover insights related to sales performance, customer trends, and product patterns using MySQL.
The dataset includes information such as branch, city, customer type, gender, product line, unit price, quantity, total, date, time, payment method, gross income, and ratings.

# Objectives
- Understand sales performance across different branches and cities  
- Identify top-performing product lines  
- Analyze customer preferences by gender  
- Find trends in gross income and ratings  
- Perform SQL-based data analysis for business insights

# Tools Used
- **MySQL Workbench**
- **CSV Dataset (Walmart Sales Data)**
- **GitHub** (for project documentation)

# Key SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY  
- Aggregate Functions (SUM, COUNT, AVG, ROUND)  
- Aliasing  
- Filtering using conditions  
- Subqueries
  
# Example Outputs
Screenshots of the queries and outputs are included in the `Results/` folder.  

# Sample Insights
- Highest total units sold by gender and product line  
- Branch-wise contribution to total gross income  
- City with highest average customer rating  
- Transactions with gross income less than 50
